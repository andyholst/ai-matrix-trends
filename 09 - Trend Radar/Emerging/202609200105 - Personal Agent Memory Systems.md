# Personal Agent Memory Systems

## Core Idea
Agents are gaining persistent memory across sessions — storing project context, coding preferences, and learned patterns to improve over time.

## Details
- **OpenCode Supermemory**: Stores project config, architecture decisions, error solutions
- **Hermes Kanban**: Work queue + session memory consolidation
- **Context7 MCP**: Up-to-date documentation injection per session
- **Challenge**: Privacy, storage, retrieval accuracy

## Why It's Emerging
Multiple approaches are competing. No clear winner yet. Privacy concerns are unresolved.
