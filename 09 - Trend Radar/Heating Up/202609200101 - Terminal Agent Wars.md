# Terminal Agent Wars

## Core Idea
Multiple AI coding agents are competing for developer mindshare in the terminal, with each taking different architectural approaches to the same problem.

## Details
- **Claude Code**: Anthropic's CLI agent, dominant in enterprise
- **OpenCode**: Open-source leader (182k stars), 75+ provider support
- **Aider**: Git-native pair programming, model-agnostic
- **Codex**: OpenAI's cloud+CLI hybrid, GPT-6 Astra default
- **Cline**: VS Code extension turned multi-platform (11M+ installs)

## Evidence
- OpenCode surpassed 182k GitHub stars in September 2026
- Cline crossed 11 million installs across all platforms
- Claude Code adopted by 67% of Fortune 500 companies
