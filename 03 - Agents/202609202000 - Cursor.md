# Cursor

## Overview

Cursor is an AI-native IDE (built as a VS Code fork) that surpassed $2B in annualized revenue by early 2026 and is used by over 67% of Fortune 500 companies including NVIDIA, Uber, and Adobe. It combines fast, context-aware tab completion with powerful agent workflows that can execute multi-file, multi-step tasks autonomously.

> **September 2026 Update**: SpaceX completed its $60B acquisition of Cursor on August 14, 2026. Grok 4.6 became Cursor's first-party model. On September 10, Cursor shipped **Projects** — a coordinator agent that plans work and delegates it to sub-agents. OpenAI notified SpaceX it intends to wind down its model supply contract with Cursor, with a proposed shutoff date of November 2026.

```bash
# Download from official site

brew install --cask cursor

# VS Code users: Cursor reads existing settings/extensions

```

## Core Capabilities

- **Agent Mode (Composer)**: multi-file, multi-step autonomous task execution with up to 8 parallel agents
- **/multitask command**: spawn parallel subagents instead of serializing work
- **Background Agents and Automations**: agents respond to events, not just human triggers
- **Supercomplete**: intent-aware autocomplete that predicts next actions, not just next tokens (72% acceptance rate)
- **Multi-model support**: Grok 4.6 (first-party), Claude, GPT, Gemini — switch per task
- **Projects coordinator agent** (September 2026): plans work and delegates to sub-agents
- **Bugbot**: automated bug-fixing agent on usage-based billing
- **Privacy Mode**: local indexing with zero data retention option
- **MCP, Skills, and Hooks** support on Pro plans
- **Cloud agents**: work on their own machines in the background while you keep coding

## Configuration

```json
// .cursor/rules or .cursorrules for project-specific instructions
{
  "model": "grok-4.6",
  "agentMode": "autonomous",
  "privacyMode": true,
  "parallelAgents": 4,
  "backgroundAgents": {
    "enabled": true,
    "trigger": "on-save"
  }
}
```

Pricing tiers: Hobby (free, limited), Pro ($20/mo), Pro+ (3x limits), Ultra (20x limits, $200/mo), Teams ($40/user/mo).

## Strengths

- Best-in-class IDE experience with inline autocomplete and agent mode
- Massive market adoption — industry standard for AI-assisted development
- Polished UX that feels native, not bolted-on
- Strong model flexibility with per-task model selection
- Background agents enable true parallel development work

## Weaknesses

- Requires internet — no offline or air-gapped support
- Context drift reported on large refactors
- Sessions stop when the app closes (no persistent background without cloud agents)
- Can become expensive at $200+/month for power users
- Pro+ pricing structure with usage-based billing can surprise teams

## Use Cases

- Everyday coding with AI augmentation (autocomplete + chat)
- Multi-file feature implementation via Agent Mode
- Teams wanting a single IDE for both humans and AI
- Rapid prototyping with parallel agents
- Developers who prefer visual, in-editor AI interaction
