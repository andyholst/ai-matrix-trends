# Jev

## Overview
Jev is TypeSafe AI's first "System One Model," released on September 15, 2026. Unlike traditional LLMs that generate text, Jev takes unstructured program state as input and returns typed, probabilistic decisions in a single parallel pass. Trained with Reinforcement Learning for Calibrated Decisions (RLCD), Jev is designed for high-volume, repeated decisions over shared state where possible answers are known in advance. It is used as a decision layer in coding agent pipelines — routing requests between models, risk-scoring tool calls, and catching prompt injection.

## Core Capabilities
- Returns typed decisions with calibrated probabilities instead of text
- 70ms–500ms end-to-end response time (40x–200x faster than frontier LLMs)
- $0.042 per 1M input tokens; output tokens are free
- Cannot hallucinate — outputs are constrained to predefined types
- Integrates with LangChain as middleware for model routing and auto-mode guardrails

## Configuration
```python
# LangChain integration
from langchain_typesafe import Noul, TypeSafeClassifier

classifier = TypeSafeClassifier()
response = classifier.invoke(
    state="The deploy failed twice and customers are seeing 500s.",
    questions={
        "urgent": Noul(instructions="Does this need attention right now?"),
    },
)
urgency = response.nouls["urgent"].noul
```

## Strengths
- Two orders of magnitude faster than frontier LLMs
- Calibrated confidence scores enable reliable automation
- Type-safe outputs eliminate parsing and validation steps
- Extremely low cost per decision

## Weaknesses
- Cannot generate text — only returns structured decisions
- Early access stage with limited real-world adoption
- Requires predefined output types, limiting flexibility
- New paradigm that requires rethinking agent architecture

## Use Cases
- Model routing in multi-model agent pipelines
- Risk-scoring tool calls before execution
- Prompt injection detection and guardrails
- High-volume classification and extraction tasks
