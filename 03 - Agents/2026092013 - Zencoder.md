# Zencoder

AI coding agent with spec-driven development (SDD) methodology. Used by Microsoft, Uber, Nvidia, Salesforce.

## Key Facts

- **Product:** Zenflow (desktop app)
- **Website:** https://zencoder.ai
- **Certifications:** SOC 2 Type II, ISO 27001, ISO 42001
- **Customers:** Microsoft, Priceline, Uber, Oracle, Lilly, Nvidia, Wrike, Salesforce, Talkdesk, Doordash, ATT, Atlassian, HP, Stanford, Chewy, PayPal, ServiceNow, Disney, Zscaler

## Architecture

- **Spec-Driven Development (SDD):** write specification first, code second
- Multi-model orchestration: plan with Opus, build with Gemini, review with Codex
- Agents for planning, coding, testing, code review
- Multi-repo indexing, architectural awareness, full dependency mapping
- Built-in quality gates: tests, linting, code review on every change

## Differentiation

- "The right model for every task" — uses different models for planning, building, reviewing
- Pre-built workflows for features, bugs, refactors
- Approval gates, role-based permissions, human-in-the-loop policies
- BYOK for existing OpenAI and Anthropic agreements
- Cloud, on-premise, or hybrid deployment
- Full audit trails, zero code storage, zero model training on data
