# SWE-2

## Overview
SWE-2 is Cognition's coding model released on September 10, 2026, post-trained from Kimi K3 (a 2.8T-parameter open-weight model). It scores 50.0% on FrontierCode 1.1 Main — within one point of Anthropic's Fable 5.1 — while costing up to 70% less to run. SWE-2 powers the Devin coding agent and represents Cognition's push to make frontier-class coding performance economically accessible.
