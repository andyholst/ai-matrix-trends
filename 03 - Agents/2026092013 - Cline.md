# Cline

## Overview
Cline is an autonomous coding agent that ships as an SDK, IDE extension (VS Code, JetBrains, Zed), and CLI assistant. With 68.8K GitHub stars under Apache 2.0, it has evolved from a VS Code chat extension into a full agentic platform. The project emphasizes context control and transparency, giving developers fine-grained oversight of agent actions. A desktop app and SDK were released in 2026, expanding Cline beyond the editor.

## Installation
```bash
# VS Code extension (most common)
# Search "Cline" in VS Code Extensions marketplace

# CLI (npm)
npm install -g @cline/cli

# Desktop app
# Download from https://cline.bot/download

# SDK
npm install @cline/sdk
```

## Core Capabilities
- Autonomous coding with plan-and-execute workflow
- Multi-file edits, terminal commands, browser interaction
- MCP (Model Context Protocol) support for custom tools
- SDK for building custom agent applications
- CLI mode with JSON output for CI/CD pipelines
- Desktop app for standalone agent sessions
- Context management with auto-compaction for long sessions
- Multi-model support: Claude, GPT, Gemini, Grok, local models
- Permission system with granular tool-level controls

## Configuration
```yaml
# .cline/config.json
{
  "model": "claude-sonnet-4-5",
  "provider": "anthropic",
  "contextWindow": 200000,
  "permissions": {
    "file_edit": "ask",
    "bash": "ask",
    "browser": "deny"
  },
  "mcpServers": {
    "custom": { "command": "npx", "args": ["-y", "my-server"] }
  }
}
```

## Strengths
- Strong context management and transparency controls
- Multi-platform: VS Code, JetBrains, Zed, CLI, desktop
- SDK enables custom agent applications
- JSON output mode for automation and CI/CD
- Apache 2.0 open source

## Weaknesses
- Less mature than Claude Code for complex multi-agent workflows
- Smaller community than OpenCode or Gemini CLI
- Desktop app still new and evolving
- Permission prompts can interrupt flow for new users

## Use Cases
- Developers wanting agent transparency and control
- Teams building custom agent applications via SDK
- CI/CD automation with JSON output mode
- Multi-editor environments (VS Code + JetBrains)
