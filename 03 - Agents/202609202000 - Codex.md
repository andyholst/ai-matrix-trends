# Codex

## Overview

Codex is OpenAI's agent-native coding platform, re-emerged in late 2025 as a serious delegation-first tool rather than just a legacy model name. It spans a cloud experience for delegated jobs, an open-source terminal CLI, IDE extensions, and a desktop app for parallel work. Codex is built for developers who want to hand off meaningful engineering work and review the results, rather than only asking for short code suggestions. In September 2026, GPT-6 Astra became the CLI's default model.

## Installation

```bash
# Install Codex CLI via curl
curl -fsSL https://chatgpt.com/codex/install.sh | sh

# Or via npm
npm install -g @openai/codex

# Or via Homebrew
brew install --cask codex

# Start using
codex
```

## Core Capabilities

- **GPT-6 Astra as default model** (September 2026); GPT-5.6 family also available (Sol, Terra, Luna)
- **Parallel agents across four surfaces**: CLI, IDE extension, desktop app, and cloud delegation
- **Multi-agent worktrees**: run agents in parallel across cloud environments and local workspaces
- **AGENTS.md convention**: hierarchical project instructions guide codebase navigation, testing, and review standards
- **Automations and Skills**: scheduled background agent runs for documentation, issue triage, CI/CD follow-up
- **Agents API** (public beta September 2026): programmatic access to the Codex harness and infrastructure
- **Codex Security** (research preview): scans 30M+ commits across 30,000+ codebases
- **ChatGPT Voice inside Codex** for hands-free interaction
- **In-app browser** for frontend development work

## Configuration

```toml
# ~/.codex/config.toml
model = "gpt-6-astra"

[model_params]
temperature = 0.2

[features]
auto_commit = true
parallel_agents = true

[cloud]
sandbox = "isolated"
timeout_minutes = 30
```

Project-level configuration via `AGENTS.md` in repository root for coding standards, testing requirements, and repo-specific practices.

## Strengths

- Strong delegation model — hand off a task, review the PR later
- Parallel cloud execution without local setup
- Deep ChatGPT ecosystem integration
- High-signal code review and test generation
- Open-source CLI with 75K+ GitHub stars and active community

## Weaknesses

- OpenAI-only models — no BYO-model support
- Cloud sandbox limits on long-running sessions
- Session gaps when cloud environments spin down
- API pricing for GPT-6 Astra ($10/$50 per million tokens) is premium
- AGENTS.md adoption still growing; not yet universal

## Use Cases

- Parallelizing bug sweeps across a codebase
- Background implementation work with PR delivery
- Teams already embedded in the OpenAI/ChatGPT ecosystem
- Delegated feature development with review-on-completion
- Scheduled automations (dependency updates, documentation refresh)
