# Cline

## Overview

Cline is an open-source (Apache 2.0) autonomous coding agent that ships as a VS Code extension, JetBrains plugin, CLI, desktop app, and SDK. With over 11 million installs across all platforms and 250+ contributors, it is one of the most widely deployed AI coding agents. Cline separates thinking from doing with its Plan mode and Act mode, giving developers structured control over how autonomously the agent operates. It works with every major LLM provider and any OpenAI-compatible endpoint.

## Installation

```bash
# VS Code extension (most common)
# Search "Cline" in VS Code marketplace or:
code --install-extension saoudrizwan.claude-dev

# CLI via npm
npm install -g cline

# Desktop app
# Download from https://cline.bot/desktop

# JetBrains plugin
# Search "Cline" in JetBrains Marketplace

# SDK
npm install @cline/sdk
```

## Core Capabilities

- **Plan mode and Act mode**: separate reasoning from execution; Plan reads and reasons, Act executes with per-step approval
- **30+ LLM providers**: Anthropic, OpenAI, Google Gemini, AWS Bedrock, Azure, OpenRouter, DeepSeek, Groq, local models via Ollama/LM Studio
- **Cline Provider** (`app.cline.bot`): pay-as-you-go inference without managing API keys
- **Multi-surface**: VS Code, JetBrains, CLI, desktop app, SDK — all share the same agent core
- **Checkpoints and rollback**: shadow Git repository tracks every change for easy undo
- **Rules and Skills**: `.clinerules` files for project-specific coding standards, architecture conventions, deployment procedures
- **MCP Marketplace**: configure MCP servers for databases, observability, and internal tools
- **Computer Use**: launch a real browser to verify UI work (with Claude models)
- **Headless mode**: run in CI/CD pipelines, cron jobs, and scripts
- **YOLO mode and Lazy Teammate Mode**: tune the safety/autonomy trade-off

## Configuration

```json
// .clinerules or .cline/rules/*.md for project rules
{
  "provider": "anthropic",
  "model": "claude-sonnet-5",
  "autoApprove": {
    "readFiles": true,
    "editFiles": false,
    "runCommands": false
  },
  "rules": {
    "codingStandards": "Follow existing patterns in src/",
    "testing": "Run tests after every change",
    "deployment": "Never deploy without explicit approval"
  }
}
```

Settings for spend limits, auto-approve categories, and per-step approval are available in the Cline panel gear icon.

## Strengths

- Fully open source and auditable — code, data flows, and Git tracking are transparent
- Model-agnostic: switch providers without changing workflow
- Plan/Act separation prevents "AI rewrote half my project" failure mode
- BYOK-optional: bring your own keys or use Cline Provider
- 11M+ installs across all platforms; strong community
- SOC 2 certified; enterprise-ready

## Weaknesses

- Per-step approval can feel slow until you configure auto-approve
- No inline tab completion (agent, not autocomplete tool)
- Computer Use requires Claude models (not available with other providers)
- Desktop app is relatively new and less mature than VS Code extension
- Resource usage can be significant with large codebases

## Use Cases

- Teams requiring open-source, auditable AI coding tools
- Developers who want model flexibility (BYO-model or self-hosted)
- Projects needing strict governance via `.clinerules` and conditional skills
- CI/CD automation with headless mode
- Developers who want explicit per-step approval for safety
