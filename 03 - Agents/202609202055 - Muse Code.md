# Muse Code

## Overview
Muse Code is Meta's first terminal-based coding agent, released in beta on August 5, 2026 and announced by Mark Zuckerberg. It is paired with Muse Spark 1.2, a model Meta built specifically for coding tasks. Muse Code is designed to handle complex coding workstreams — building, debugging, and shipping — and enters a market where DeepSWE scores above 70 already exist, making it competitive but not state of the art at launch.

## Installation
```bash
# Install Muse Code CLI
curl https://dev.meta.ai/install.sh | bash
```

## Core Capabilities
- Terminal-based coding agent (CLI-first, like Claude Code and Codex CLI)
- Paired with Muse Spark 1.2, a model purpose-built for coding
- Handles complex coding workstreams: build, debug, ship
- Designed for large codebases
- Cloud-hosted model (no local deployment)

## Configuration
```bash
# Muse Code uses environment variables for configuration
export MUSE_API_KEY="<your-api-key>"
# Configuration via .muse/ directory in project root
```

## Strengths
- Backed by Meta's AI infrastructure and resources
- Purpose-built coding model (Muse Spark 1.2)
- CLI-first design familiar to developers
- Competitive entry into the coding agent market

## Weaknesses
- New entrant with limited real-world adoption
- Muse Spark 1.3 already shows benchmark scores that don't match real-world output
- Cloud-only — no local deployment option
- Tied to Meta's ecosystem

## Use Cases
- Developers already in the Meta ecosystem
- Teams wanting a CLI coding agent backed by a major lab
- Complex coding workstreams requiring cloud-scale compute
