# Claude Code

## Overview

Claude Code is Anthropic's terminal-native agentic coding tool, widely regarded in 2026 as the most capable "coding brain" among AI development agents. It reads entire repositories, reasons about architecture, debugs subtle bugs, and coordinates changes across multiple files — all from the shell. In mid-2026 it operates as a surface-agnostic agent: the same core runs in the terminal, as a VS Code and JetBrains extension, as a GitHub Action that opens PRs, and inside claude.ai on web and mobile.

> **September 2026 Update**: Claude Fable 5.1 reached Claude Code the week of August 31 with a 1M-token context window, 128K max output, and 75% cheaper cache reads ($0.25/MTok vs $1.00). Anthropic prices it at $10/$50 per 1M tokens. On the official Terminal-Bench 4.0 leaderboard, Fable 5.1 in Claude Code leads at 57.9%. New features include per-message effort, turn-scoped system messages, readable progress updates between tool calls, and content provenance with EU AI Act watermarking.

## Installation

```bash
# Install via npm
npm install -g @anthropic-ai/claude-code

# Or via curl installer
curl -fsSL https://claude.ai/install.sh | sh

# Start using
claude
```

## Core Capabilities

- **1M-token context window** by default on current models (Fable 5.1, Opus 5, Sonnet 5), with no long-context price premium
- **Claude Fable 5.1** (September 2026): stronger long-running agentic coding, multistep research, document/spreadsheet/slide work; 75% cheaper cache reads
- **Dynamic Workflows**: orchestrate tens to hundreds of background agents with sub-agents nested five levels deep
- **Parallel sub-agents**: launch specialized agents (Explore, Plan, general-purpose) concurrently; assign different models and reasoning budgets per worker
- **Multi-surface**: terminal CLI, VS Code extension, JetBrains plugin, GitHub Actions, web/mobile via claude.ai
- **Skills, hooks, and plugins**: package extensions across projects; slash commands and MCP server support
- **Self-hosted runners**: turn your own machines into execution targets for cloud-async work
- **`/goal` command**: agent continues working across turns until a completion condition is met
- **`/loop` command**: recurring prompts for periodic tasks

## Configuration

```json
{
  "model": "claude-sonnet-5",
  "permissions": {
    "allow": [
      "Read",
      "Write",
      "Edit",
      "Bash",
      "WebFetch",
      "WebSearch"
    ]
  },
  "hooks": {
    "pre-commit": "npm test",
    "post-edit": "eslint --fix"
  }
}
```

Key environment variables: `ANTHROPIC_API_KEY`, `CLAUDE_CODE_MAX_OUTPUT_TOKENS`, `CLAUDE_CODE_ENABLE_AUTO_UPDATES`.

## Strengths

- Deepest reasoning and debugging capability of any coding agent in 2026
- 1M-token default context window handles large refactors without context loss
- Per-subagent model and effort control — use Opus for hard tasks, Haiku for cheap ones
- Polished across terminal, IDE, browser, and mobile surfaces
- Extensive plugin/hook ecosystem and strong GitHub integration

## Weaknesses

- Anthropic-only models — no BYO-model flexibility
- Token pricing can be significant on large workloads (Opus: $5/$25 per million tokens)
- No built-in inline autocomplete (terminal tool, not an IDE)
- Max plan ($200/month) may still be insufficient for heavy parallel agent usage

## Use Cases

- Large-repository refactors that require sustained context
- Complex debugging sessions across multiple files and services
- Architectural planning with parallel exploration agents
- Delegated implementation work via GitHub Actions (issue-to-PR)
- Teams already invested in the Anthropic ecosystem
