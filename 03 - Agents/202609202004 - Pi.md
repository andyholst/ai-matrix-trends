# Pi

## Overview
Pi is an open-source, terminal-native coding agent that supports multiple model providers and emphasizes local execution with privacy. It positions itself as a lightweight alternative to Claude Code and OpenCode, with a focus on simplicity and model flexibility. Pi supports local models via Ollama and remote providers through a unified CLI interface.

## Installation
```bash
# Install Pi via npm
npm install -g @anthropic/pi

# Or install via curl
curl -fsSL https://pi.dev/install.sh | sh

# Verify installation
pi --version
```

## Core Capabilities
- Terminal-native agentic coding
- Multi-provider model support (Claude, GPT, Gemini, local via Ollama)
- Git worktree isolation for parallel sessions
- MCP server support
- Lightweight with minimal configuration
- Local model execution for privacy-sensitive work

## Configuration
```yaml
# ~/.pi/config.yaml
model:
  provider: anthropic
  name: claude-sonnet-4-20250514
  fallback: ollama/llama3.1
agent:
  worktrees: true
  max_parallel: 3
  auto_commit: false
mcp:
  enabled: true
  servers:
    - name: filesystem
      path: /usr/bin/mcp-fs
```

## Key Plugins/Extensions
- MCP server ecosystem
- Ollama local model provider
- Git worktree manager

## Strengths
- Lightweight and fast
- Multi-provider model flexibility
- Local model support for privacy
- Simple configuration
- Open source with active community

## Weaknesses
- Smaller feature set than Claude Code or OpenCode
- Less polished IDE integration
- Community still growing
- Fewer enterprise features

## Use Cases
- Privacy-sensitive development
- Developers who want local model execution
- Lightweight terminal workflows
- Multi-provider model experimentation
