# AWS Kiro

## Overview
AWS Kiro is Amazon's spec-driven agentic development environment, launched as a competitor to Cursor and GitHub Copilot. Kiro emphasizes a structured workflow where developers write specifications first, then the agent generates code from those specs. It is still finding its footing in the market but represents AWS's bet on enterprise agentic development.

## Installation
```bash
# Kiro is available as a VS Code extension and standalone IDE
# Install from https://kiro.dev/
# VS Code extension: ext install kiro.kiro
```

## Core Capabilities
- Spec-driven development: write specs, generate code
- AWS-native deployment integration
- Multi-file agentic edits
- Enterprise security with AWS IAM integration
- Cloud formation and infrastructure-as-code support

## Configuration
```yaml
# .kiro/config.yaml
model: claude-sonnet-4-20250514
spec_format: markdown
agent:
  autonomy: spec_gated
  max_files_per_task: 20
aws:
  region: us-east-1
  deploy_target: ecs
  iam_role: kiro-developer
```

## Key Plugins/Extensions
- AWS CDK integration
- CloudFormation generator
- ECS/EKS deployment hooks
- VS Code and JetBrains extensions

## Strengths
- Spec-driven approach reduces hallucination
- Deep AWS ecosystem integration
- Enterprise-grade security model
- Infrastructure-as-code generation

## Weaknesses
- Still finding product-market fit
- Smaller community than established players
- AWS-centric — less appealing for multi-cloud teams
- Limited third-party model support

## Use Cases
- AWS-centric development teams
- Infrastructure-heavy projects
- Enterprises with strict spec/compliance requirements
- Developers who prefer spec-first workflows
