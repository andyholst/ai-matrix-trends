# Claw Code

## Overview
Claw Code is a clean-room Rust reimplementation of the Claude Code CLI agent architecture, built by the UltraWorkers community. It emerged in early 2026 after the Claude Code source leak and became the fastest repository in GitHub history to reach 100K stars (now 195K+). The project is licensed under MIT and is explicitly not affiliated with Anthropic. It is described as an "agent-managed museum exhibit" — developed and maintained with no human intervention, using a suite of autonomous harness agents (LazyCodex, Gajae-Code, oh-my-codex) that plan, execute, verify, and label changes.

## Installation
```bash
# Clone and build from source (Rust required)
git clone https://github.com/ultraworkers/claw-code
cd claw-code/rust
cargo build --workspace

# Set your API key
export ANTHROPIC_API_KEY="sk-ant-..."

# Verify
./target/debug/claw doctor

# Run
./target/debug/claw
```

## Core Capabilities
- Full Claude Code CLI parity: interactive sessions, prompt mode, slash commands
- Multi-provider support: Anthropic, OpenAI-compatible, Ollama (local), MLX (Apple Silicon)
- Hierarchical AGENTS.md knowledge base for project-specific agent instructions
- Plugin system with slash commands and custom tools
- Session resumption and checkpointing
- Docker/Podman container workflow support
- Windows (PowerShell), macOS, Linux support

## Configuration
```yaml
# .claw.json or .claude.json
{
  "model": "claude-sonnet-4-5",
  "provider": "anthropic",
  "max_iterations": "unlimited",
  "tools": {
    "bash": true,
    "file_edit": true,
    "web_search": true
  }
}
```

## Strengths
- Fastest GitHub repo to 100K stars in history
- MIT licensed, fully open source
- Rust implementation offers performance and memory safety
- Agent-managed development is a novel experiment in autonomous coding
- Broad provider and platform support

## Weaknesses
- Build-from-source only (no pre-built binaries via package managers)
- Not affiliated with Anthropic — no official Claude model access guarantees
- Experimental; the "museum exhibit" framing signals it is not a production tool
- Smaller ecosystem than Claude Code itself

## Use Cases
- Developers wanting a Claude Code-compatible agent without Anthropic dependency
- Experimentation with autonomous agent-managed repositories
- Local/offline coding with Ollama or MLX backends
