# Devin Desktop

## Overview
Devin Desktop is the rebranded Windsurf IDE, renamed on June 2, 2026 when Cognition unified all its products under the Devin brand. The Agent Command Center (Spaces, Kanban view, multi-agent management) is now the primary interface, while the classic Windsurf editor experience remains fully accessible. Devin Desktop serves as the local command center for managing teams of local and cloud agents working alongside developers.

## Installation
```bash
# Devin Desktop is delivered as an over-the-air update to existing Windsurf users
# New users can download from:
# https://devin.ai/desktop
```

## Core Capabilities
- Agent Command Center with Spaces, Kanban view, and multi-agent management
- Full Windsurf IDE features preserved (editor, extensions, keybindings, LSPs)
- Supports both local-only agents and Devin Cloud agents
- Reads `.devin/rules/`, `.windsurf/rules/`, `AGENTS.md`, and `.cursor/rules` (`.mdc`)
- Directory-based rules with activation triggers (always-on, model-decision, glob-based, manual)

## Configuration
```yaml
# Devin Desktop uses .devin/ directory for project configuration
# Legacy .windsurf/ configs are automatically migrated
rules:
  location: .devin/rules/
  format: markdown
  triggers:
    - always-on
    - model-decision
    - glob-based
    - manual
```

## Strengths
- Unified brand across Devin Cloud, Desktop, CLI, and Review
- Existing Windsurf users keep all settings, extensions, and workflows
- Agent Command Center provides a single pane for multi-agent management
- No pricing change for existing users

## Weaknesses
- Rebranding may confuse existing Windsurf users
- Agent-centric UI may not appeal to developers who prefer traditional IDE workflows
- Tied to Cognition's ecosystem for full cloud agent functionality

## Use Cases
- Developers who want a local IDE with integrated agent management
- Teams using Devin Cloud who need a local command center
- Windsurf users transitioning to the Devin ecosystem
