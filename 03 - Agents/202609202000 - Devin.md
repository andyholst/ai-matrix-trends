# Devin

## Overview
Devin is Cognition AI's cloud-native autonomous coding agent, positioned as the "assign a task and come back later" tool for defined backlog jobs. In June 2026, Cognition renamed Windsurf to Devin Desktop, unifying the IDE and cloud agent under one brand. Devin runs in a sandboxed cloud environment, reads from a repo, plans the work, writes code, and opens a pull request — all without local setup.

## Installation
```bash
# Devin is a cloud service — no local CLI install required
# Sign up at https://devin.ai/
# Devin Desktop (formerly Windsurf) can be downloaded from https://devin.ai/desktop
```

## Core Capabilities
- Cloud-based autonomous coding with sandboxed execution
- Issue-to-PR workflow: assign a GitHub issue, Devin plans and implements
- Parallel agent runs for multiple tasks
- Built-in browser for testing and verification
- Git worktree support for isolated agent sessions
- Sub-agent support and sandboxing (via Devin Local)

## Configuration
```yaml
# devin.yaml — project-level configuration
agent:
  model: claude-sonnet-4-20250514
  sandbox: docker
  worktrees: true
  max_parallel_agents: 4
notifications:
  slack: true
  email_on_pr: true
```

## Key Plugins/Extensions
- GitHub integration (issue-to-PR flow)
- Slack notifications
- Devin Desktop IDE (VS Code fork)

## Strengths
- Most hands-off workflow — ideal for well-defined backlog items
- No local environment setup required
- Strong cloud sandboxing for safe execution
- Unified brand with Devin Desktop IDE

## Weaknesses
- Loops on vague or underspecified tasks
- Weak results on ambiguous requirements
- Base fee plus usage pricing can escalate
- Less control compared to terminal-native agents

## Use Cases
- Delegating well-scoped bug fixes
- Backlog grooming and ticket implementation
- Teams that want cloud-first agent execution
- Developers who prefer reviewing PRs over pair-programming
