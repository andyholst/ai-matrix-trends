# Kilo Code

## Overview
Kilo Code is an all-in-one agentic engineering platform with 27.4K GitHub stars under MIT license. It positions itself as a VS Code agent focused on context control, offering a unified platform for building, shipping, and iterating on software. Kilo Code supports multiple AI providers and emphasizes collaborative features like a shared agent board for team coordination.

## Installation
```bash
# VS Code extension
# Search "Kilo Code" in VS Code Extensions marketplace

# CLI
npm install -g @kilo/code

# JetBrains plugin
# Available in JetBrains marketplace
```

## Core Capabilities
- All-in-one agentic engineering platform (build, ship, iterate)
- Multi-provider support: Claude, GPT, Gemini, and others
- Kilo Swarm: shared agent board for team collaboration
- Context management with preflight compaction threshold
- VS Code and JetBrains IDE integration
- CLI for terminal-based workflows
- Visual regression testing skill
- Agent behavior customization (experimental features)

## Configuration
```yaml
# .kilo/config.json
{
  "model": "claude-sonnet-4-5",
  "provider": "anthropic",
  "experimental": {
    "shared_agent_board": true
  },
  "context": {
    "preflight_compaction_threshold": 0.85
  },
  "skills": {
    "vscode_visual_regression": true
  }
}
```

## Key Plugins/Extensions
- Kilo Swarm — shared agent board for team coordination
- VS Code Extension — editor-native agent
- JetBrains Plugin — IntelliJ/PyCharm integration
- Visual Regression Skill — automated UI testing

## Strengths
- Strong focus on context management and control
- Kilo Swarm enables team-level agent coordination
- MIT licensed and open source
- Multi-provider flexibility
- Visual regression testing integration

## Weaknesses
- Smaller community than OpenCode or Cline (27K stars)
- Less mature ecosystem of plugins
- Shared agent board is experimental
- Fewer third-party integrations than competitors

## Use Cases
- Teams wanting collaborative agent workflows
- Projects requiring strong context control
- Developers who want multi-provider flexibility in VS Code
- Teams experimenting with shared agent boards
