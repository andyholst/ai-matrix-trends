# Windsurf

## Overview
Windsurf was a popular AI coding IDE built on VS Code, known for its Cascade agent. In September 2026, Cognition (the company behind Devin) removed the Cascade agent from Windsurf and folded the product into Devin Desktop. This marked the end of Windsurf as a standalone coding agent. Cognition simultaneously released SWE-2 (post-trained from Kimi K3) at 50.0% on FrontierCode 1.1 Main and raised over $2B at a $48B valuation.

## Installation
```bash
# Windsurf is now Devin Desktop
# See https://docs.devin.ai/desktop for installation
```

## Core Capabilities
- **Cascade agent removed** (September 8, 2026) — no longer available in Windsurf
- **Devin Desktop** — the successor product with SWE-2 model
- **SWE-2 model** — post-trained from Kimi K3, 50.0% on FrontierCode 1.1 Main
- **IDE-based coding** — VS Code fork with AI-native features
- **Agentic workflows** — planning, coding, testing in a single surface

## Strengths
- **SWE-2 model** — competitive benchmark performance (50.0% FrontierCode 1.1)
- **Strong backing** — $48B valuation, $2B+ raised
- **IDE-native** — familiar VS Code-based experience
- **Agentic workflows** — end-to-end development automation

## Weaknesses
- **Cascade agent removed** — the core AI feature is gone from Windsurf
- **Product uncertainty** — folded into Devin Desktop, future direction unclear
- **Closed-source** — unlike [[202609202000 - Cline]] or [[202609200758 - OpenCode]]
- **Vendor lock-in** — tied to Cognition's ecosystem
