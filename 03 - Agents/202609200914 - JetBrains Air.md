# JetBrains Air

## Overview
JetBrains Air is a new Agentic Development Environment (ADE) launched in public preview in March 2026. It allows developers to run multiple AI agents — Claude Agent, Codex, Gemini CLI, and Junie — side by side in isolated execution environments (Docker containers or Git worktrees). Air focuses on the workflow around agents rather than the models themselves: code-aware task definition, isolated execution, context-aware review, and workspaces for managing concurrent tasks. It is agent-agnostic, letting you switch models per task or compare outputs side by side.

## Installation
```bash
# Install via JetBrains Toolbox
# 1. Install Toolbox: https://www.jetbrains.com/toolbox-app/
# 2. Search for "Air" in Toolbox apps
# 3. Install and launch

# Or download directly from https://air.dev/
```

## Core Capabilities
- Multi-agent parallelism: run Claude, Codex, Gemini CLI, Junie concurrently
- Isolated execution via Docker containers or Git worktrees
- Code-aware task definition (symbols, classes, methods, commits)
- Context-aware review throughout the project
- Workspaces to manage concurrent tasks without branch collisions
- Agent-agnostic — switch models per task or compare outputs
- BYOK (Bring Your Own Key) or JetBrains AI subscription

## Configuration
```yaml
# air.config.yaml
agents:
  - name: claude
    provider: anthropic
    model: claude-opus-4-8
  - name: codex
    provider: openai
    model: gpt-5.3-codex
  - name: gemini
    provider: google
    model: gemini-3-pro

execution:
  isolation: "worktree"  # or "docker"
  maxConcurrent: 4
  reviewMode: "context-aware"
```

## Key Plugins/Extensions
- Claude Agent (Anthropic)
- Codex (OpenAI)
- Gemini CLI (Google)
- Junie (JetBrains)
- JetBrains Central integration (unified control plane)

## Strengths
- Only ADE supporting multiple agent harnesses natively
- Isolated execution prevents branch collisions
- Code-aware task definition understands project structure
- Backed by JetBrains' IDE expertise
- BYOK flexibility — use your own API keys
- JetBrains AI Pro/Ultimate subscription included

## Weaknesses
- Still in preview — not production-ready
- No JetBrains AI Free or Enterprise support
- Requires JetBrains Toolbox for installation
- Smaller community than established agents
- Limited to supported agents (no custom harnesses yet)

## Use Cases
- Developers wanting to compare multiple AI agents on the same task
- Teams needing isolated parallel agent execution
- Projects requiring different models for different tasks
- JetBrains ecosystem users wanting agentic workflows
