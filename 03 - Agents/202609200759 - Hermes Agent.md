# Hermes Agent

## Overview
Hermes Agent is a self-hosted, self-improving AI agent built by Nous Research. It provides a powerful CLI for managing plugins, models, tools, and gateways. The agent reached 247k GitHub stars and global rank #19 by September 2026. Unlike coding-specific agents, Hermes is a general-purpose agent with persistent memory, self-created skills, and a messaging gateway connecting to Telegram, Discord, Slack, WhatsApp, Signal, and email.

## Installation
```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

## Core Capabilities
- **Self-improving skills** — creates skills from experience, improves them during use
- **Persistent memory** — learns from interactions and grows with the user over time
- **Messaging gateway** — connects to Telegram, Discord, Slack, WhatsApp, Signal, and email
- **Tool ecosystem** — browser, terminal, file operations, web search, code execution
- **Plugin architecture** — extensible via skills and plugins
- **Multi-model support** — works with various LLM providers

## Configuration
```bash
hermes config set
hermes model
hermes tools
hermes gateway
hermes setup
```

## Strengths
- **Fastest-growing** open-source AI agent (247k stars, GitHub #19 globally)
- **Self-improving** — unique learning loop that creates and refines skills
- **Multi-channel** — works across messaging platforms, not just IDE/terminal
- **Self-hosted** — full data control for privacy-conscious users
- **General-purpose** — not limited to coding; handles research, automation, communication
- **Active development** — v0.21.3 released September 14, 2026

## Weaknesses
- **Not coding-specialized** — less optimized for software engineering than [202609202000 - Claude Code](202609202000%20-%20Claude%20Code.md) or [202609200758 - OpenCode](202609200758%20-%20OpenCode.md)
- **Younger project** — less mature tooling than established coding agents
- **Smaller coding-specific community** compared to coding-focused agents
- **Self-hosting overhead** — requires infrastructure management

## Use Cases
- **Personal AI assistant** across messaging platforms
- **Self-hosted agent** for privacy-sensitive workflows
- **Multi-channel automation** — Telegram, Discord, Slack bots
- **General-purpose agent** that can code but also research, write, and automate
- **Learning agent** that improves from user interaction over time
