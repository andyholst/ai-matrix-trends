# Qwen Code

Open-source AI coding agent by Alibaba's Qwen team. 28k GitHub stars, 3.1k forks.

## Key Facts

- **Developer:** Alibaba Qwen team
- **Repository:** https://github.com/QwenLM/qwen-code
- **License:** Apache-2.0
- **Stable release:** v0.24.0 (2026-09-16), alongside Qwen Code Desktop

## Architecture

- Multi-protocol, multi-platform agent framework
- Deep integrations for Qwen models; no vendor lock-in
- Originally based on Google Gemini CLI v0.8.2; independent since v0.1
- Terminal-native CLI with web-shell and desktop companion
- MCP support, agentic coding, full TypeScript implementation

## Differentiation

- Open-source model + framework evolve together
- Qwen3-Coder-Next: small hybrid model for agentic coding with good speed/reasoning
- No telemetry fork available on Reddit (r/LocalLLaMA)
- Free tier ended Apr 15; community discussing migration plans
