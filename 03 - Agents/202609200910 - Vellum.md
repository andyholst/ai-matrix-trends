# Vellum

## Overview
Vellum is an open-source personal AI assistant that goes beyond code editing to manage the full surface area of a developer's work — tickets, communications, research, calendar, and codebase context. It features a three-layer persistent memory system (workspace files, curated knowledge base, auto-extracted long-term memory with confidence scoring) that carries context across every session and surface. Vellum runs locally on macOS or in a sandboxed cloud container, with native apps for macOS, iOS, web, Slack, Telegram, email, and voice.

## Installation
```bash
# macOS (native app)
brew install --cask vellum

# Or download from https://www.vellum.ai/account/signup
# Cloud deployment: one-click via Vellum Cloud dashboard
```

## Core Capabilities
- Persistent three-layer memory with auto-extraction and reinforcement tracking
- Multi-surface presence: macOS, iOS, web, Slack, Telegram, email, voice
- Proactive workflow awareness — tracks tickets, flags blockers, surfaces follow-ups
- Manages Linear tickets, sends Slack messages, reads inbox, drafts replies
- Builds complete working applications from natural language descriptions
- 35+ open-source plugins for code review, testing, deployment automation
- Sandboxed credentials — LLM never sees raw credential values
- Multi-model: OpenAI, Anthropic, Google, OpenRouter, Fireworks, Ollama

## Configuration
```yaml
# ~/.vellum/workspace/IDENTITY.md — persona and tone
# ~/.vellum/workspace/SOUL.md — values and preferences
# ~/.vellum/workspace/USER.md — user profile
# ~/.vellum/workspace/NOW.md — current context, loaded every session

# skills/SKILL.md — custom skill definition
# permissions.yaml — granular tool-level access controls
```

## Key Plugins/Extensions
- Code review automation
- Testing workflow plugins
- Deployment automation
- Google Workspace, Slack, Notion integrations
- Community plugin catalog at skills.sh

## Strengths
- Only tool combining coding capability with persistent memory and proactive workflow management
- Open-source (MIT) with local-first option — data stays on your machine
- Broadest channel coverage of any assistant (9 channels)
- Self-improving skills that learn from interactions
- Enterprise-grade security with sandboxed credentials and pod-level isolation

## Weaknesses
- No Windows app (macOS only for native desktop)
- Plugin ecosystem still growing compared to OpenClaw/Hermes
- Paid plans required for full managed cloud features
- Not a dedicated IDE — no inline autocomplete or manual code editing workflow

## Use Cases
- Developers who want AI to manage their full workflow, not just code
- Teams needing persistent context across sessions and channels
- Individuals wanting a private, self-hosted AI assistant with memory
- Cross-functional work spanning code, tickets, and communications
