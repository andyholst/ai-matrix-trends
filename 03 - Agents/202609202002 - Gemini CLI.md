# Gemini CLI

## Overview
Gemini CLI is Google's terminal-first AI coding agent, providing an agent-mode approach to coding tasks powered by Gemini models. It represents Google's entry into the sync-CLI pattern pioneered by Aider, offering a free entry point for developers already in the Google ecosystem. Gemini CLI supports multi-file edits, command execution, and autonomous task completion directly from the terminal.

## Installation
```bash
# Requires Node.js 18+
npm install -g @google/gemini-cli

# Or via npx (no install)
npx @google/gemini-cli
```

## Core Capabilities
- Terminal-native agentic coding with Gemini models
- Multi-file code generation and refactoring
- Shell command execution and iteration
- Free tier available (rate-limited)
- Integration with Google Cloud services

## Configuration
```yaml
# ~/.gemini/settings.json
{
  "model": "gemini-2.5-pro",
  "sandbox": "workspace-write",
  "autoAccept": false,
  "theme": "dark"
}
```

## Strengths
- Free entry point for agentic coding
- Strong performance on Google Cloud and GCP workloads
- Terminal-native workflow familiar to CLI users
- Gemini 2.5 Pro model competitive on coding benchmarks

## Weaknesses
- Smaller ecosystem than Claude Code or Codex
- Less mature agentic loop than competitors
- Rate limits on free tier
- Limited IDE integration compared to Cursor or Copilot

## Use Cases
- Developers in Google Cloud ecosystem
- Budget-conscious teams wanting free agentic coding
- Terminal-centric workflows
- Prototyping and experimentation
