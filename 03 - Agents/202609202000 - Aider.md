# Aider

## Overview

Aider is an open-source terminal AI pair programmer that brings LLM-powered development directly into your command line and git repository. Model-agnostic by design, it works with Claude, GPT, Gemini, DeepSeek, Grok, and local models via Ollama. Aider's standout philosophy is treating git as the source of truth: every AI edit becomes an atomic, auto-generated commit that you can diff, manage, and revert with standard git commands. It is frequently cited as the most honest tool for solo development work with a real test suite.

## Installation

```bash
# Install via pip
python -m pip install aider-install
aider-install

# Or via pipx (recommended for isolation)
pipx install aider

# Or via Homebrew
brew install aider

# Start using in any git repository
cd your-project
aider
```

## Core Capabilities

- **Repository mapping**: builds a tree-sitter-parsed map of your entire codebase, showing function signatures, class definitions, and cross-file imports without loading every file into context
- **Architect mode**: pairs a planning model with a cheaper editing model, cutting session costs
- **Atomic Git commits**: every AI edit is a discrete commit with a generated message — clean audit trail
- **100+ programming languages**: Python, JavaScript, Rust, Ruby, Go, C++, PHP, HTML, CSS, and dozens more
- **Model-agnostic**: switch between Claude, GPT, Gemini, DeepSeek, Grok, or local models with `/model` mid-session
- **Watch mode**: file-watching detects AI comments in source and implements requested changes automatically
- **Linting and testing**: automatically runs linters and test suites after each edit, feeding failures back to the model
- **Voice-to-code**: speak requests instead of typing
- **IDE/editor agnostic**: works in VS Code, JetBrains, Vim, Emacs, or any terminal
- **Image and web page context**: add screenshots and reference docs to the chat
- **Copy/paste to web chat**: streamline back-and-forth with a browser interface

## Configuration

```bash
# Basic usage
aider --model sonnet --api-key anthropic=<key>

# DeepSeek
aider --model deepseek --api-key deepseek=<key>

# Local model via Ollama
aider --model ollama/llama3.1

# Architect mode with separate editor model
aider --architect --editor-model gpt-4o-mini

# Watch mode (auto-implement AI comments in source)
aider --watch

# Disable auto-commits (manual git workflow)
aider --no-auto-commits
```

Configuration via `.aider.conf.yml` for persistent settings (model, API keys, ignore patterns).

## Strengths

- True model-agnostic architecture — switch providers mid-session without changing workflow
- Atomic Git commits create a clean, reviewable, bisectable change record
- Free and open source; near-zero ongoing cost with local or cheap models
- Repository mapping handles large codebases without manual file selection
- Architect mode reduces costs by separating planning from editing
- Terminal-native — no IDE lock-in, works over SSH

## Weaknesses

- No inline tab completion (pure agent, not autocomplete)
- Auto-commits create noisy PR history in squash-merge workflows
- No SOC 2 certification or enterprise compliance documentation
- No built-in cloud delegation (local-only execution)
- Architect mode with premium models can still be expensive
- No native IDE integration (terminal-first by design)

## Use Cases

- Solo development with a real test suite and git-based workflow
- Large refactors where atomic commits enable safe bisection
- Developers who want model flexibility and cost control
- Remote/SSH development where terminal-native tools are preferred
- Teams using squash-merge workflows (with `--no-auto-commits`)
