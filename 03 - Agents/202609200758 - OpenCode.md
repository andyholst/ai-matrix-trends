# OpenCode

## Overview
OpenCode is an open-source, MIT-licensed AI coding agent built with a client-server architecture and a polished terminal TUI. It has become the most-starred open-source coding agent on GitHub (182k+ stars as of September 2026), offering broad model support (75+ providers), a desktop app, and IDE surfaces. It is the go-to choice for developers seeking a vendor-neutral, BYOK (bring your own key) alternative to closed-source agents like [[202609202000 - Claude Code]].

## Installation
```bash
curl -fsSL https://opencode.ai/v2/install | bash
```

## Core Capabilities
- **75+ LLM providers** via OpenAI-compatible API, including OpenAI, Anthropic, Google, local models (Ollama), and many more
- **Client-server architecture** enabling headless operation, remote access, and multi-surface usage
- **Desktop app** (shipped September 2026) alongside the TUI and IDE integrations
- **BYOK model** — no vendor lock-in, use your own API keys
- **ACP integration** for Zed, Neovim, and Emacs
- **Free tier** available with supported providers

## Configuration
```yaml
# ~/.config/opencode/opencode.json
{
  "provider": {
    "myprovider": {
      "npm": "@ai-sdk/openai-compatible",
      "options": { "baseURL": "https://api.myprovider.com/v1" },
      "models": { }
    }
  }
}
```

## Strengths
- **Largest open-source community** in the coding agent space (182k+ GitHub stars)
- **Most providers supported** — 75+ vs. competitors' typical 5–10
- **No vendor lock-in** — BYOK architecture with MIT license
- **Polished TUI** that rivals paid competitors
- **Desktop app** brings agentic coding to non-terminal users
- **Free tier** makes it accessible for individual developers

## Weaknesses
- **No first-party model** — relies entirely on third-party providers
- **Less deep IDE integration** than [[202609202000 - Cline]] or [[202609202000 - Cursor]]
- **Smaller benchmark presence** than [[202609202000 - Claude Code]] or [[202609202000 - Codex]]
- **Newer desktop app** — still maturing compared to established IDE extensions

## Use Cases
- Developers who want a **free, open-source** coding agent with no vendor lock-in
- Teams using **multiple LLM providers** and wanting a single interface
- **Terminal-native** developers who prefer TUI over IDE extensions
- **BYOK environments** where data cannot leave the organization
- **Multi-model workflows** — switch between providers per task
