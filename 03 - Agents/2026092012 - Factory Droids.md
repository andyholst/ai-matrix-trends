# Factory Droids

Autonomous AI agents for enterprise engineering teams. Raised $200M at $5B valuation.

## Key Facts

- **Developer:** Factory (factory.ai)
- **Founded:** 2023 by Matan Grinberg and Eno Reyes
- **Funding (Sept 15, 2026):** $200M at $5B valuation, tripled from $1.5B in April
- **Investors:** Blackstone, Khosla Ventures, Sequoia Capital, Insight Partners, Evantic Capital, Sound Ventures
- **Customers:** Nvidia, Adobe, and others

## Architecture

- "Software factories" positioning — agents handle end-to-end software development
- Competes with Cognition (Devin) and Cursor
- Focus on enterprise engineering teams
- CEO quote: "move from individual coding agents to software factories that serve as the core foundation from which an entire software company operates"

## Differentiation

- Autonomous agents that build, test, and maintain software
- Rapid valuation growth: $1.5B → $5B in five months
- Focus on enterprise workforce reshaping (similar to Coinbase, Block layoffs citing AI productivity)
