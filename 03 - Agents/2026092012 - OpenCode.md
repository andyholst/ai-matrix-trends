# OpenCode

## Overview
OpenCode is an open-source, provider-agnostic AI coding agent with 209K+ GitHub stars under MIT license. Originally created by SST and now maintained by Anomaly, it supports virtually every frontier model (Claude, GPT, Gemini, Grok, DeepSeek, local models) through a unified terminal interface. It has become the most-starred open-source coding agent, with 950+ contributors and a desktop app in beta.

## Installation
```bash
# YOLO install
curl -fsSL https://opencode.ai/install | bash

# Package managers
npm i -g opencode-ai@latest
brew install anomalyco/tap/opencode    # macOS/Linux (recommended)
sudo pacman -S opencode               # Arch Linux
paru -S opencode-bin                  # Arch Linux (AUR latest)
mise use -g opencode                  # Any OS
nix run nixpkgs#opencode              # Nix

# Desktop app
brew install --cask opencode-desktop  # macOS
```

## Core Capabilities
- Provider-agnostic: Claude, GPT, Gemini, Grok, DeepSeek, local/Ollama models
- Built-in agents: `build` (full-access), `plan` (read-only), `@general` (subagent)
- Terminal UI with Tab key agent switching
- Desktop app (beta) for macOS, Windows, Linux
- SDK for programmatic integration
- Session management and resumption
- MCP server support
- Multi-language i18n (20+ languages)
- Nix flake support for reproducible dev environments

## Configuration
```yaml
# .opencode/config.json
{
  "model": "anthropic/claude-sonnet-4-5",
  "provider": "anthropic",
  "agents": {
    "build": { "tools": ["bash", "file_edit", "web"] },
    "plan": { "readOnly": true }
  },
  "mcp": {
    "servers": {
      "my-server": { "command": "npx", "args": ["-y", "my-mcp"] }
    }
  }
}
```

## Strengths
- Most-starred open-source coding agent (209K+ stars)
- Truly provider-agnostic — no vendor lock-in
- MIT licensed with massive community (950+ contributors)
- Desktop app available across all major platforms
- Supports local models via Ollama for offline use

## Weaknesses
- Less polished than commercial alternatives (Cursor, Claude Code)
- Provider-agnostic means no deep optimization for any single model
- Desktop app still in beta
- Smaller plugin ecosystem than VS Code-native agents

## Use Cases
- Developers who want model flexibility without vendor lock-in
- Teams using multiple AI providers simultaneously
- Offline/air-gapped development with local models
- Open-source purists wanting full code auditability
