# RooCode

## Overview
RooCode is a reliability-first AI coding agent designed for large-scale changes and complex refactoring. It emerged as a fork/alternative to Cline with a focus on stability and predictable behavior on big codebases. RooCode supports multiple providers, custom modes, and is particularly popular among developers working on large monorepos who need dependable agentic behavior.

## Installation
```bash
# VS Code Extension Marketplace
# Search: "Roo Code"
# Or via CLI:
code --install-extension rooveterinaryinc.roo-cline
```

## Core Capabilities
- Reliability-focused agentic loop for large changes
- Multi-provider support (Anthropic, OpenAI, local models)
- Custom modes for different task types
- Large monorepo handling
- Git-native workflow with diff review

## Configuration
```yaml
# .vscode/settings.json
{
  "roo.provider": "anthropic",
  "roo.model": "claude-sonnet-4-20250514",
  "roo.mode": "code",
  "roo.autoApprove": false,
  "roo.maxTokens": 128000
}
```

## Strengths
- Exceptional reliability on large codebases
- Multi-provider flexibility (not locked to one vendor)
- Custom modes for different task types
- Strong git integration and diff review
- Active open-source community

## Weaknesses
- VS Code only (no terminal or other IDEs)
- Less polished UI than Cursor or Windsurf
- Smaller market share than front-runners
- Documentation less comprehensive than competitors

## Use Cases
- Large monorepo refactoring
- Teams needing multi-provider flexibility
- Developers wanting open-source agent
- Complex multi-file changes requiring reliability
