# Kilo Code

## Overview
Kilo Code is a rising VS Code agent focused on context control and structured modes. It has gained traction in developer communities for its tighter context handling, addressing frustration with hallucinating agents. Kilo Code offers structured agent modes that give developers more predictable and controllable AI coding experiences within the VS Code ecosystem.

## Installation
```bash
# VS Code Extension Marketplace
# Search: "Kilo Code"
# Or via CLI:
code --install-extension kilo-code.kilo-code
```

## Core Capabilities
- Structured agent modes for predictable behavior
- Tight context control to reduce hallucinations
- VS Code-native integration
- Multi-file editing with explicit context boundaries
- Configurable autonomy levels

## Configuration
```yaml
# .vscode/settings.json
{
  "kilo.mode": "structured",
  "kilo.contextStrategy": "explicit",
  "kilo.autoApprove": false,
  "kilo.maxContextFiles": 10
}
```

- Less proven on large enterprise codebases
