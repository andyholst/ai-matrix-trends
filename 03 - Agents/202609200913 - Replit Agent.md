# Replit Agent

## Overview
Replit Agent (now at version 4) is an AI coding agent that builds, tests, and publishes complete applications from natural language descriptions — all within Replit's cloud workspace. Agent 4 introduces a design canvas for visual UI exploration, parallel task execution, multi-user collaboration via kanban boards, and the ability to build mobile apps, web apps, landing pages, decks, and videos in the same project. It targets both beginners and teams who want to go from prompt to deployed product without local setup.

## Installation
```bash
# No local installation required — browser-based
# Sign up at https://replit.com/signup

# Optional: Replit CLI for local development
npm install -g @replit/cli
```

## Core Capabilities
- Builds complete, deployable apps from natural language prompts
- Agent 4: design canvas with visual UI exploration and variant generation
- Parallel task execution — agents work on auth, database, backend, frontend simultaneously
- Multi-user collaboration with kanban task management
- Real browser testing — agent tests its own work and fixes issues
- Converts existing web apps to mobile apps
- Integrates with Linear, Notion, Excel, and other services
- One-click deployment with custom domains

## Configuration
```yaml
# replit.nix — project configuration
# .replit — run commands, environment variables

# Agent 4 settings
agent:
  mode: "parallel"  # or "sequential"
  designCanvas: true
  autoTest: true
  autoDeploy: false
```

## Key Plugins/Extensions
- Design canvas with variant generation
- Mobile app converter
- Database integration (Replit DB)
- Authentication templates
- Deployment with custom domains
- Linear / Notion / Excel integrations

## Strengths
- Zero setup — entirely browser-based
- Fastest path from idea to deployed product
- Agent 4's design canvas bridges visual design and code
- Multi-user collaboration with task prioritization
- Handles full stack: auth, database, backend, frontend, deployment
- First prompt is free

## Weaknesses
- Cloud-only — requires internet connection
- Less control over infrastructure compared to local development
- Vendor lock-in to Replit platform
- Not suitable for large existing codebases
- Limited model choice compared to Claude Code or Codex

## Use Cases
- Rapid prototyping and MVP building
- Beginners learning to build apps
- Teams wanting collaborative AI-driven development
- Converting web apps to mobile
- Building landing pages, decks, and marketing sites
