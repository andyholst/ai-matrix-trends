# Pareto

## Overview
Pareto is a composite AI model from Unbiased, launched on September 17, 2026. It is not a single model but a blend that runs multiple LLMs in parallel on every request and synthesizes one answer, drawing on both frontier and open models. The composition can change between releases. Pareto is multimodal, supports a 262K context window, and is priced at $2.50/$7.50 per 1M tokens. It is available through Unbiased's API and OpenRouter.

## Installation
```bash
# Pareto is available via OpenRouter API
# Sign up at https://openrouter.ai/ or https://unbiased.ai/
# Python SDK:
pip install openrouter-sdk
```

## Core Capabilities
- Composite model: runs multiple LLMs per request and keeps the best answer
- Multodal: supports text and image input
- 262K context window
- $2.50/$7.50 per 1M tokens (input/output)
- 85.95% cache hit rate on OpenRouter
- Vendor-reported benchmarks: 74 on DeepSWE, 51 on Terminal-Bench 4.0

## Configuration
```python
# OpenRouter SDK
from openrouter import OpenRouter

client = OpenRouter(api_key="<OPENROUTER_API_KEY>")
response = client.chat.completions.create(
    model="unbiased/pareto",
    messages=[{"role": "user", "content": "Write a Python function to sort a list."}],
)
```
