# Amp

Sourcegraph's AI coding agent and dev environment, built around persistent cloud "Orbs."

## Key Facts

- **Developer:** Sourcegraph (spun out as standalone company)
- **Website:** https://ampcode.com
- **Desktop app shipped:** 2026-09-04
- **Free tier announced:** 2026-09-13 (BYO compute + model keys)

## Architecture

- **Orbs:** persistent cloud dev environments where agents keep running after you close your laptop
- Agents wake on outside events: new Linear issue, CI failure, self-set schedules
- **Multiplayer:** invite team members into the same orb to share control
- Built on Sourcegraph's semantic code graph for cross-repo understanding
- **Restack feature** (Sept 11): turns all changes into a cleaner commit set
- **Steer, Don't Queue** (Sept 4): messages redirect running agents instead of waiting
- CLI for local dev; `amp sync` mirrors orb changes locally while agent runs remotely
- `amp --no-tui` for servers, CI runners

## Differentiation

- "One Runner Is Now Enough" (Sept 17): a single runner can serve many directories
- Orbs described as paradigm shift comparable to early Claude Code
- Agents can run for days, coordinating with other orbs, sleeping when offloading work
