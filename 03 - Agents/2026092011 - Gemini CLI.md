# Gemini CLI

## Overview
Gemini CLI is Google's open-source terminal-native AI coding agent, bringing Gemini models directly into the command line. With 107K+ GitHub stars and Apache 2.0 licensing, it has become one of the fastest-growing CLI coding agents. It offers a generous free tier (60 requests/min, 1,000 requests/day with a personal Google account) and supports the full Gemini 3 model family with 1M token context windows.

## Installation
```bash
# Run instantly with npx (no install)
npx @google/gemini-cli

# Install globally with npm
npm install -g @google/gemini-cli

# Homebrew (macOS/Linux)
brew install gemini-cli

# Preview release
npm install -g @google/gemini-cli@preview
```

## Core Capabilities
- Terminal-first AI agent with Gemini 3 model access
- Built-in tools: Google Search grounding, file operations, shell commands, web fetching
- MCP (Model Context Protocol) support for custom integrations
- Multimodal: generate apps from PDFs, images, or sketches
- Conversation checkpointing to save and resume sessions
- Custom context files (GEMINI.md) for project-specific behavior
- Non-interactive/scriptable mode for CI/CD automation
- VS Code IDE companion extension

## Configuration
```yaml
# .gemini/settings.json
{
  "model": "gemini-3-pro",
  "contextWindow": 1000000,
  "tools": {
    "googleSearch": true,
    "fileOperations": true,
    "shellCommands": true
  },
  "mcpServers": {
    "custom-server": {
      "command": "npx",
      "args": ["-y", "my-mcp-server"]
    }
  }
}
```

## Strengths
- Generous free tier with personal Google account
- 1M token context window on Gemini 3 models
- Google Search grounding for real-time information
- Apache 2.0 open source with strong community
- Weekly release cadence (preview, stable, nightly channels)

## Weaknesses
- Tied to Google ecosystem and Gemini models
- Free tier has rate limits (60 req/min, 1,000 req/day)
- Less mature than Claude Code or Codex for complex refactoring
- Requires Google account for authentication

## Use Cases
- Developers already in the Google Cloud ecosystem
- Cost-conscious teams wanting a free-tier CLI agent
- Tasks benefiting from Google Search grounding
- Multimodal coding (sketch/PDF to code)
