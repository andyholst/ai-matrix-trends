# Nimbalyst

## Overview
Nimbalyst is an open-source visual workspace that wraps around Claude Code and OpenAI Codex, adding visual management, planning tools, and multi-session orchestration. It provides a kanban board for running multiple agent sessions in parallel, inline AI diffs across markdown, mockups, diagrams, code, and data models. Nimbalyst doesn't replace your IDE — it sits above your existing agent harnesses to provide a unified visual layer for planning, reviewing, and coordinating AI-driven development.

## Installation
```bash
# Linux
wget https://github.com/Nimbalyst/nimbalyst/releases/latest/download/Nimbalyst-Linux.AppImage
chmod +x Nimbalyst-Linux.AppImage

# macOS (Apple Silicon)
wget https://github.com/Nimbalyst/nimbalyst/releases/latest/download/Nimbalyst-macOS-arm64.dmg

# macOS (Intel)
wget https://github.com/Nimbalyst/nimbalyst/releases/latest/download/Nimbalyst-macOS-x64.dmg

# Windows
wget https://github.com/Nimbalyst/nimbalyst/releases/latest/download/Nimbalyst-Windows.exe
```

## Core Capabilities
- Visual kanban board for managing multiple Claude Code / Codex sessions
- Parallel agent sessions with one-click worktree isolation per session
- Inline AI diffs across markdown, CSV, mockups, diagrams, code, data models
- Context-aware editing — agents understand full project structure
- Side-by-side AI assistance without context switching
- Review and approve AI edits with full visibility into file changes
- Extension marketplace for additional editors and tools
- Multiplayer collaboration for teams

## Configuration
```yaml
# nimbalyst.config.yaml
agents:
  - name: claude-code
    model: claude-opus-4-8
    harness: claude-code
  - name: codex
    model: gpt-5.3-codex
    harness: codex

workspace:
  worktreeIsolation: true
  maxParallelSessions: 6
  reviewMode: inline-diff
```

## Key Plugins/Extensions
- Markdown editor with AI sidebar
- CSV spreadsheet editor
- UI mockup editor
- Excalidraw diagram editor
- Mermaid diagram editor
- Data model / ER diagram editor
- Mind map editor
- In-app browser preview
- Calc Sheet with live results

## Strengths
- Only open-source visual workspace for Claude Code and Codex
- Agent-first architecture — uses best-in-class models directly
- Works on existing codebases with no migration
- Free for individuals
- Cross-platform: macOS, Windows, Linux
- Trusted by teams at Automattic, Amazon, Redfin, Zillow, Twilio

## Weaknesses
- Not an IDE — no inline autocomplete or manual code editing
- Requires familiarity with Claude Code or Codex
- Still maturing — extension ecosystem growing
- No native model inference — relies on external agent harnesses

## Use Cases
- Developers running multiple Claude Code / Codex sessions in parallel
- Teams needing visual coordination of AI-driven development
- Projects requiring planning, mockups, and code in one workspace
- Code review workflows with inline AI diffs
