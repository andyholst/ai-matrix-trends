# Augment

## Overview
Augment is a code-intelligence platform that combines deep repository understanding with agentic coding capabilities. It positions itself as a powerful alternative for enterprise teams that need large-context code analysis and multi-file refactors. Despite strong technical capabilities, Augment has been hurt by pricing changes in 2026 that made it less competitive against Cursor and Claude Code.

## Installation
```bash
# Augment is available as a VS Code extension and standalone IDE
# Install from https://augmentcode.com/
# VS Code extension: ext install augmentcode.augment
```

## Core Capabilities
- Deep codebase indexing and semantic search
- Multi-file agentic edits with large context windows
- Code graph navigation for understanding dependencies
- Enterprise-grade security and compliance
- Custom model fine-tuning on private repos

## Configuration
```yaml
# .augment/config.yaml
indexing:
  max_repo_size: 10GB
  languages: [python, typescript, go, rust, java]
agent:
  model: augment-large
  context_window: 256k
  autonomy_level: high
enterprise:
  sso: true
  audit_log: true
  data_residency: us-east-1
```

## Key Plugins/Extensions
- VS Code extension
- JetBrains plugin
- CLI for CI/CD integration

## Strengths
- Excellent code intelligence and repository understanding
- Strong enterprise features (SSO, audit logs, data residency)
- Large context windows for big refactors
- Custom model fine-tuning

## Weaknesses
- Pricing changes in 2026 hurt competitiveness
- Smaller community than Cursor or Claude Code
- Less terminal-native workflow
- Extension ecosystem still growing

## Use Cases
- Enterprise teams with large monorepos
- Codebase onboarding and dependency analysis
- Security-conscious organizations
- Teams needing custom model fine-tuning
