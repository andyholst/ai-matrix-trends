# Notion MCP

## Overview
Notion MCP is the official Model Context Protocol server for Notion workspaces. It exposes pages, databases, and knowledge base content to AI coding agents, enabling them to read project documentation, query task databases, and retrieve structured context without manual copy-paste. Supports HTTP transport with OAuth authentication.

## Installation
```bash
# Claude Code
claude mcp add notion -- npx -y @notionhq/mcp-server

# Or use the hosted remote endpoint
# https://mcp.notion.com/mcp
```

## Configuration
```yaml
mcpServers:
  notion:
    type: http
    url: https://mcp.notion.com/mcp
    headers:
      Authorization: Bearer ${NOTION_INTEGRATION_TOKEN}
    # Or local stdio:
    # command: npx
    # args: ["-y", "@notionhq/mcp-server"]
    # env:
    #   NOTION_TOKEN: ${NOTION_INTEGRATION_TOKEN}
```

## Use Cases
- Retrieving project specs and requirements from Notion pages
- Querying task databases for sprint planning
- Grounding agent responses in team documentation
- Searching knowledge bases for relevant context
