# Hermes Jev

## Overview
Hermes Jev is the official Jev plugin for Hermes Agent (v0.2.1.2, KeelTrace). It implements an asynchronous decision nervous system for Hermes Agent with turn admission, adaptive local routing, confidence-gated challenges, typed decisions, verification, and context governance. This is the plugin installed and active in the default Hermes profile on this host.

The plugin provides 8 tools and 3 hooks that integrate TypeSafe AI's System One decision model (Jev) directly into Hermes's runtime.

## Installation
```bash
# From Hermes plugin catalog
hermes plugins install hermes-jev

# Or from source
git clone https://github.com/keeltrace/hermes-jev ~/.hermes/plugins/hermes-jev
hermes plugins enable hermes-jev
```

## Configuration
```yaml
# ~/.hermes/config.yaml
plugins:
  entries:
    hermes-jev:
      settings:
        jev_provider: typesafe
        gate_mode: advisory
        gate_scope: all
        nervous_mode: correct_next
```

## Provided Tools
| Tool | Description |
|------|-------------|
| `jev_decide` | Make one bounded typed decision |
| `jev_rank` | Rank a bounded set of candidates |
| `jev_verify` | Verify an execution result |
| `jev_assess` | Ask up to 16 native Jev questions |
| `jev_context_curate` | Context-value governor over explicit evidence |
| `jev_context_rehydrate` | Restore sanitized evidence |
| `jev_stats` | Return local Hermes-Jev telemetry |
| `jev_nervous_event` | Emit structured material decisions |

## Provided Hooks
- `pre_tool_call` — Intercept tool calls for Jev validation
- `post_tool_call` — Verify tool results
- `pre_llm_call` — Route LLM calls through Jev

## Use Cases
- Intelligent context governance for long-horizon agents
- Adaptive model routing — pick cheapest capable model
- Tool-call validation with confidence scoring
- Jailbreak/prompt-injection screening at 40-200x faster than LLM
- Async decision nervous system for multi-agent workflows

## Compatibility
- **Agent:** Hermes Agent 1.0+ (native)
- **Dependencies:** uv, Python 3.10+, TypeSafe API key (for LangChain integration)
