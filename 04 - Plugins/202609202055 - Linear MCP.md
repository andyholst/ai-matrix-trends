# Linear MCP

## Overview
Linear MCP is a Model Context Protocol server that connects AI coding agents to Linear's project management platform. Agents can read issues, cycles, and project updates, create tickets, and track progress — all from the terminal. Designed for high-velocity startup teams that want their AI assistant to participate in project management workflows.

## Installation
```bash
# Claude Code
claude mcp add linear -- npx -y @linear/mcp-server

# Or use the hosted endpoint
# https://mcp.linear.app/mcp
```

## Configuration
```yaml
mcpServers:
  linear:
    type: http
    url: https://mcp.linear.app/mcp
    headers:
      Authorization: Bearer ${LINEAR_API_KEY}
    # Or local stdio:
    # command: npx
    # args: ["-y", "@linear/mcp-server"]
    # env:
    #   LINEAR_API_KEY: ${LINEAR_API_KEY}
```

## Use Cases
- Creating issues from bug reports or feature requests
- Querying sprint progress and cycle status
- Linking code changes to Linear tickets
- Generating standup summaries from issue activity
