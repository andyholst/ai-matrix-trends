# Supabase MCP

## Overview
Supabase MCP is the official Model Context Protocol server for the Supabase platform. It gives AI coding agents direct access to Postgres databases, authentication, storage, edge functions, and SQL workflows. Agents can run scoped or read-only queries, inspect schema, and reason about slow queries without leaving the conversation. Supports HTTP transport with OAuth or API key auth.

## Installation
```bash
# Claude Code
claude mcp add supabase -- npx -y @supabase/mcp-server

# Remote hosted endpoint (no local install)
# Point config at https://mcp.supabase.com/mcp
```

## Configuration
```yaml
mcpServers:
  supabase:
    type: http
    url: https://mcp.supabase.com/mcp
    headers:
      Authorization: Bearer ${SUPABASE_ACCESS_TOKEN}
    # Or local stdio:
    # command: npx
    # args: ["-y", "@supabase/mcp-server"]
    # env:
    #   SUPABASE_URL: https://your-project.supabase.co
    #   SUPABASE_SERVICE_ROLE: ${SUPABASE_SERVICE_ROLE}
```

## Use Cases
- Inspecting database schema and relationships
- Running read-only queries to debug data issues
- Managing edge functions and storage buckets
- Reasoning about slow queries and index usage
