# Stripe MCP

## Overview
Stripe MCP is the official Model Context Protocol server for Stripe. It enables AI coding agents to interact with payment intents, subscriptions, customers, disputes, and billing data. Agents can search customers, create payment links, manage subscriptions, and reason about revenue metrics — all through natural language. Supports HTTP transport with OAuth or API key auth.

## Installation
```bash
# Claude Code
claude mcp add stripe -- npx -y @stripe/mcp-server

# Or use the hosted endpoint
# https://mcp.stripe.com/mcp
```

## Configuration
```yaml
mcpServers:
  stripe:
    type: http
    url: https://mcp.stripe.com/mcp
    headers:
      Authorization: Bearer ${STRIPE_SECRET_KEY}
    # Or local stdio:
    # command: npx
    # args: ["-y", "@stripe/mcp-server"]
    # env:
    #   STRIPE_SECRET_KEY: ${STRIPE_SECRET_KEY}
```

## Use Cases
- Creating payment links or subscriptions from the terminal
- Searching customers by email or metadata
- Debugging failed payments and disputes
- Generating revenue reports and metrics
