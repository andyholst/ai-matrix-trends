# Cursor Rules

## Overview
Cursor Rules is Cursor's configuration system for customizing agent behavior. Rules are markdown files stored in .cursor/rules/ that define coding standards, preferred patterns, and project-specific instructions. They can be scoped to file types or directories, allowing fine-grained control over how Cursor's agent operates in different parts of a codebase.
