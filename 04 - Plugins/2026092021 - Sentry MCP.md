# Sentry MCP

## Overview
Sentry MCP is the official Model Context Protocol server for Sentry, giving AI coding agents direct access to error tracking, performance monitoring, and session replay data. With 858+ stars and active development (1,220+ commits), it enables agents to query issues, analyze stack traces, and triage errors without leaving the coding environment. It supports both stdio and HTTP transports and ships as a Claude Code plugin.

## Key Features
- **Issue management:** List, search, and resolve Sentry issues; view issue details and events
- **Stack trace analysis:** Fetch and analyze stack traces with context
- **Performance data:** Query transactions, spans, and performance metrics
- **Session replay:** Access session replay metadata for debugging
- **Project & organization:** List projects, teams, and organizations
- **AI-powered tools:** Optional LLM-backed issue summarization and suggested fixes

## Installation
```bash
# Claude Code (HTTP - recommended)
claude mcp add sentry --transport http https://mcp.sentry.dev/mcp

# Claude Desktop / Cursor
{
  "mcpServers": {
    "sentry": {
      "url": "https://mcp.sentry.dev/mcp"
    }
  }
}

# Claude Code plugin
/plugin install sentry-mcp@claude-plugins-official
```

## Configuration
- `SENTRY_ACCESS_TOKEN` — Sentry access token (for stdio mode)
- `SENTRY_HOST` — Custom Sentry host (for self-hosted instances)
- `OPENAI_API_KEY` or `OPENROUTER_API_KEY` — For AI-powered tools (optional)
- Experimental features: append `?experimental=1` to the MCP URL

## Use Cases
- Triage production errors directly from agent conversations
- Correlate errors with recent deployments
- Analyze performance regressions with transaction data
- Generate suggested fixes using AI-powered tools
- Debug issues with session replay context

## Compatibility
- **Agent:** Claude Code, Claude Desktop, Cursor, Windsurf, VS Code
- **Transports:** stdio (local), HTTP (remote)
- **Auth:** Sentry access token or OAuth
