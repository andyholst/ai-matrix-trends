# Codex Cloud Tasks

## Overview
Codex Cloud Tasks is OpenAI's task queue system for the Codex agent. Users can submit coding tasks to a cloud queue where Codex agents pick them up, execute them in isolated environments, and return pull requests. Tasks run in parallel, with each agent having its own containerized workspace and git branch.
