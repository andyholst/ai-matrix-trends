# Exa MCP

## Overview
Exa MCP is a semantic search engine purpose-built for AI agents. Unlike traditional keyword search, Exa ranks results by meaning and relevance, making it ideal for coding agents that need to find the most pertinent sources on a topic rather than just matching strings. It supports both stdio and HTTP transports and integrates with Claude Code, Cursor, Codex, and other MCP-compatible clients.

## Installation
```bash
# Claude Code
claude mcp add exa -- npx -y exa-mcp-server

# Cursor / VS Code MCP config
{
  "mcpServers": {
    "exa": {
      "command": "npx",
      "args": ["-y", "exa-mcp-server"],
      "env": { "EXA_API_KEY": "your-key" }
    }
  }
}
```

## Configuration
```yaml
# ~/.config/claude-code/mcp.json or equivalent
mcpServers:
  exa:
    command: npx
    args: ["-y", "exa-mcp-server"]
    env:
      EXA_API_KEY: ${EXA_API_KEY}
    # Optional: limit results per query
    maxResults: 5
```

## Use Cases
- Finding the most relevant documentation or blog posts on a technical topic
- Competitor research: "find the top 5 vector database comparisons"
- Semantic code search across public repositories
- Grounding agent responses in real, cited sources
