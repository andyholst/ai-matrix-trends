# Context7 MCP

## Overview
Context7 is an open-source Model Context Protocol server built by Upstash that gives AI coding agents access to up-to-date, version-specific documentation for any library or framework. Instead of relying on training data that may be months out of date, agents query Context7 at runtime to fetch the exact docs for the version they are working with. The server has rapidly become one of the most popular MCP servers in the ecosystem — 62K+ GitHub stars and a Hacker News front-page appearance signal strong adoption. It works with any MCP-compatible agent: Claude Code, Cursor, Windsurf, OpenCode, and others.

## Installation
```bash
# For Claude Code
claude mcp add --transport http context7 https://mcp.context7.com/mcp \
  --header "Authorization: Bearer $CONTEXT7_API_KEY"

# For Cursor / Windsurf / OpenCode (add to MCP config JSON)
{
  "mcpServers": {
    "context7": {
      "command": "npx",
      "args": ["-y", "@upstash/context7-mcp"],
      "env": {
        "CONTEXT7_API_KEY": "your-key"
      }
    }
  }
}
```

## Configuration
```json
{
  "mcpServers": {
    "context7": {
      "url": "https://mcp.context7.com/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_CONTEXT7_API_KEY"
      }
    }
  }
}
```

## Use Cases
- Giving agents access to current React, Next.js, Vue, or other framework docs without retraining
- Eliminating hallucinated API calls caused by outdated training data
- Supporting enterprise on-prem deployments for air-gapped environments
- Reducing prompt size by fetching docs on-demand instead of pasting them into context
