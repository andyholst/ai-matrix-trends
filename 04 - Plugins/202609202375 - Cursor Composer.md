# Cursor Composer

## Overview
Cursor Composer is Cursor's multi-file editing agent. It can understand an entire codebase, plan changes across multiple files, and execute them as a cohesive unit. Composer uses a 'spec' approach where it first describes what it will do, then makes all the edits in a single pass. It supports parallel editing and can handle complex refactoring tasks.
