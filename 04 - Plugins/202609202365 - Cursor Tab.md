# Cursor Tab

## Overview
Cursor Tab is Cursor's native AI code completion and generation feature. Unlike external plugins, Tab is built directly into the Cursor IDE editor, providing inline code suggestions, multi-line completions, and diff-based edits. It uses a fine-tuned model optimized for code editing patterns and integrates with Cursor's codebase indexing for context-aware suggestions.
