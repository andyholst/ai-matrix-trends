# OpenCodeRAG

## Overview
OpenCodeRAG is a local-first Retrieval-Augmented Generation plugin for OpenCode that enables semantic code search powered by locally-hosted embedding models. It uses tree-sitter for intelligent code chunking across 300+ languages and LanceDB as the vector database. By default, embeddings are generated locally via Ollama, ensuring no source code or embeddings leave the machine. The plugin also provides evaluation tools to measure RAG injection overhead and compare token usage with and without RAG.

## Installation
```bash
# Install the CLI
npm install -g opencode-rag

# Or add as an OpenCode plugin
# ~/.config/opencode/config.json

{
  "plugin": ["opencode-rag"]
}

# Initialize the runtime
opencode-rag setup
```

## Configuration
```json
{
  "plugin": ["opencode-rag"],
  "rag": {
    "embeddingModel": "ollama/nomic-embed-text",
    "vectorDb": "lancedb",
    "chunkSize": 512,
    "chunkOverlap": 64,
    "autoInjectMinScore": 0.75,
    "recallMinScore": 0.72,
    "autoInjectTopK": 1
  }
}
```

## Use Cases
- Semantic code search across large codebases
- Context-aware code completion with RAG injection
- Documentation retrieval and Q&A
- Code review with relevant context surfacing
- Token usage evaluation and optimization
