# Zapier MCP

## Overview
Zapier MCP is the official Model Context Protocol server for Zapier's automation platform. It connects AI coding agents to over 6,000 app automations, enabling them to trigger workflows, create records, and interact with SaaS tools — all through natural language. Agents can discover available actions, understand their parameters, and execute them without leaving the terminal. Supports HTTP transport with OAuth.

## Installation
```bash
# Claude Code
claude mcp add zapier -- npx -y @zapier/mcp-server

# Or use the hosted endpoint
# https://mcp.zapier.com/mcp
```

## Configuration
```yaml
mcpServers:
  zapier:
    type: http
    url: https://mcp.zapier.com/mcp
    headers:
      Authorization: Bearer ${ZAPIER_ACCESS_TOKEN}
    # Or local stdio:
    # command: npx
    # args: ["-y", "@zapier/mcp-server"]
    # env:
    #   ZAPIER_API_KEY: ${ZAPIER_API_KEY}
```

## Use Cases
- Triggering Zapier workflows from the terminal
- Creating records in CRM, project management, or marketing tools
- Automating cross-app data sync
- Discovering available Zapier actions for a given app
