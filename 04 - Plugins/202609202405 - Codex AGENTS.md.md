# Codex AGENTS.md

## Overview
Codex AGENTS.md is OpenAI's configuration file for customizing Codex agent behavior. Similar to CLAUDE.md for Claude Code, it allows teams to define coding standards, architectural patterns, and operational procedures. The file supports hierarchical configuration with project-level, directory-level, and file-level rules.
