# Datadog MCP

## Overview
Datadog MCP is the official Model Context Protocol server for Datadog's unified observability platform. It enables AI coding agents to search logs, check alert status, pull dashboard data, and reason about metrics and traces. Agents can diagnose issues by querying observability data directly, without switching to the Datadog UI. Supports HTTP transport with API key auth.

## Installation
```bash
# Claude Code
claude mcp add datadog -- npx -y @datadog/mcp-server

# Or use the hosted endpoint
# https://mcp.datadoghq.com/mcp
```

## Configuration
```yaml
mcpServers:
  datadog:
    type: http
    url: https://mcp.datadoghq.com/mcp
    headers:
      DD-API-Key: ${DATADOG_API_KEY}
      DD-APPLICATION-Key: ${DATADOG_APP_KEY}
    # Or local stdio:
    # command: npx
    # args: ["-y", "@datadog/mcp-server"]
    # env:
    #   DATADOG_API_KEY: ${DATADOG_API_KEY}
    #   DATADOG_APP_KEY: ${DATADOG_APP_KEY}
    #   DATADOG_SITE: datadoghq.com
```

## Use Cases
- Searching logs for error patterns
- Checking alert status and incident context
- Pulling dashboard metrics for reports
- Correlating traces with code changes
