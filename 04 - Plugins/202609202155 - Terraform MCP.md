# Terraform MCP

## Overview
Terraform MCP is the official Model Context Protocol server from HashiCorp for Terraform. It enables AI coding agents to plan, apply, and manage infrastructure as code directly from the terminal. Agents can inspect state, validate configurations, and reason about resource dependencies — making infrastructure management conversational. Supports stdio transport.

## Installation
```bash
# Claude Code
claude mcp add terraform -- npx -y @hashicorp/terraform-mcp-server

# Or install the binary directly
brew install hashicorp/tap/terraform-mcp-server
```

## Configuration
```yaml
mcpServers:
  terraform:
    command: npx
    args: ["-y", "@hashicorp/terraform-mcp-server"]
    env:
      TF_WORKDIR: ./infra
      TF_TOKEN: ${TF_API_TOKEN}
    # Or local binary:
    # command: terraform-mcp-server
    # args: ["--tf-workdir", "./infra"]
```

## Use Cases
- Planning and applying Terraform changes from the terminal
- Inspecting current state and drift
- Validating configurations before deployment
- Reasoning about resource dependencies and modules
