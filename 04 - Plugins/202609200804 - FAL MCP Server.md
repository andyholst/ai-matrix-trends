# FAL MCP Server

## Overview
FAL MCP Server is a hosted Model Context Protocol endpoint that connects any MCP-compatible AI agent to FAL's catalog of 1,000+ generative AI models. It lets agents search models, inspect input schemas, run inference, and retrieve outputs across image generation, video synthesis, audio creation, 3D generation, and upscaling — all through standardized MCP tool calls. The server is fully stateless and hosted on Vercel, requiring no local infrastructure. It works with Claude Code, Claude Desktop, Cursor, Windsurf, and any other MCP client.

## Installation
```bash
# For Claude Code
claude mcp add --transport http fal-ai https://mcp.fal.ai/mcp \
  --header "Authorization: Bearer $FAL_KEY"

# For Cursor / Windsurf (add to MCP config JSON)
{
  "mcpServers": {
    "fal-ai": {
      "url": "https://mcp.fal.ai/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_FAL_KEY"
      }
    }
  }
}
```

## Configuration
```json
{
```

## Use Cases
- Generating images, videos, or audio from natural language prompts without leaving the agent session
- Letting the agent search the FAL model catalog and pick the right model for a task
- Chaining FAL outputs into downstream agent workflows (e.g., generate a thumbnail, then post to a CMS)
- Rapid prototyping of UI mockups via FLUX or Stable Diffusion models
