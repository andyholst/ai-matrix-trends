# Figma MCP

## Overview
Figma MCP is the official Model Context Protocol server for Figma. It gives AI coding agents programmatic access to Figma files, components, design tokens, and layout information. Agents can inspect designs, extract spacing and color values, and reason about component structure — bridging the gap between design and code. Supports HTTP transport with OAuth.

## Installation
```bash
# Claude Code
claude mcp add figma -- npx -y @figma/mcp-server

# Or use the hosted endpoint
# https://mcp.figma.com/mcp
```

## Configuration
```yaml
mcpServers:
  figma:
    type: http
    url: https://mcp.figma.com/mcp
    headers:
      Authorization: Bearer ${FIGMA_ACCESS_TOKEN}
    # Or local stdio:
    # command: npx
    # args: ["-y", "@figma/mcp-server"]
    # env:
    #   FIGMA_API_KEY: ${FIGMA_API_KEY}
```

## Use Cases
- Extracting design tokens (colors, spacing, typography) for code
- Inspecting component structure before implementation
- Validating that UI matches Figma designs
- Generating code from Figma component layouts
